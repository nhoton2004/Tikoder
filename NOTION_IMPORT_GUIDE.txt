# 📖 Hướng Dẫn Import LEARNING_GUIDE.md vào Notion

## **Cách 1: Copy-Paste trực tiếp (Nhanh nhất)**

1. **Mở Notion** → Tạo page mới
2. **Mở file `LEARNING_GUIDE.md`** (em đã tạo tại `/home/nho/TikTokOrderApp/LEARNING_GUIDE.md`)
3. **Copy toàn bộ nội dung**
4. **Paste vào Notion** → Notion sẽ tự động format markdown

---

## **Cách 2: Dùng Notion Importer (Format tốt hơn)**

1. **Notion → Import** (3 dots menu)
2. **Chọn "Markdown"**
3. **Upload file `LEARNING_GUIDE.md`**
4. Notion sẽ import đầy đủ structure, headings, code blocks

---

## **Cách 3: Dùng Web Clipper**

Nếu đại ca muốn em tạo HTML version:

```bash
# Dùng pandoc convert markdown → HTML
pandoc LEARNING_GUIDE.md -o LEARNING_GUIDE.html
```

Rồi use Notion Web Clipper để clip HTML.
